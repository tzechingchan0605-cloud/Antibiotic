# Noto CJK 香港字形

`NotoSansHK-paper.otf` 由建置程式使用 FontTools `pyftsubset` 從 Noto Sans CJK HK Regular 產生，保留中英文及科學符號。來源預設為 Linux `fonts-noto-cjk` 的 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`，香港字形為 collection index 4。可用 `PAPER_CJK_FONT` 指定相同 HK collection 的完整字型路徑。

原字型及其子集遵從 [SIL Open Font License 1.1](LICENSE.txt)。字型隨材料提供；PDF 保留可選取文字及字形資源，學生無須安裝字型。每次依目前兩語列印內容更新字形，不沿用 VL1 的有限字符子集。
